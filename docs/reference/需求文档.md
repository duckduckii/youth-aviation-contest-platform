项目名称：全国青少年安全与应急科普创新大赛 - 创新设计赛（航模方向）作品提交系统
需求来源：UI/原型设计文档 (网页设计想法.pptx)
核心目标：构建一个允许学生在线提交参赛作品的Web系统，需明确区分“知识类”与“创新设计类”两种赛道，并重点实现“创新设计类”的复杂文件提交流程。

一、 系统核心模块与功能点

1.  用户登录模块
    ◦   登录凭证：

        ▪   账号：学生的报名号。

        ▪   初始密码：该报名号的后八位。

    ◦   登录后状态：页面应显示当前登录的账号，并提供“修改密码”和“退出登录”的功能入口。

2.  比赛方向选择模块（关键分流点）
    ◦   选项：提供“知识类”和“创新设计类”两个单选按钮。

    ◦   交互流程：

        1.  用户选择任一方向后，必须弹出确认对话框。
        2.  确认对话框内容示例（以选择“知识类”为例）：
            ▪   标题/提示文字：“您确认选择知识类比赛吗？一旦确定则无法更改”

            ▪   按钮：“是” 与 “否”。

    ◦   业务规则：用户确认选择后，此选择不可更改。系统需根据用户的选择，导航至对应的提交流程页面。

3.  创新设计类作品提交模块（核心功能）
    ◦   页面布局：应提供一个表单页面，包含以下可提交项，每项需附带“上传”和“修改”按钮：

        ▪   作品研究设计报告

        ▪   其他证明材料1

        ▪   其他证明材料2

        ▪   诚信承诺书

        ▪   提交日期（可能为系统自动生成或用户选择）

    ◦   最终操作：页面底部需有“提交”按钮，用于最终提交所有材料。

4.  文件上传详细规格（针对“创新设计类”）
    系统需为每一个上传项强制执行以下格式和命名规则：

提交项 是否必填 文件格式 大小限制 文件名规则（示例） 内容说明

1. 作品设计报告 是 PDF 未明确，建议设定 {作品题目}.pdf 作品的研究设计报告正文。

2. 其他证明材料1 是 PDF ≤ 30 MB {作品题目}证明材料1.pdf 可包含设计图纸、图表、实物照片、等比例模型照片、仿真模型照片等。

3. 其他证明材料2 是 MP4 ≤ 100 MB {作品题目}证明材料2.mp4 作品的功能演示视频。

4. 诚信承诺书 是 PDF 未明确 未强制，但需处理上传 需为已由学生和指导教师签字的扫描件。系统应提前提供下载。

    ◦   文件名处理逻辑：在上传时，系统应能接收用户命名的文件，但最终存储或提交校验时，可能需要依据规则检查或重命名。前端可做格式提示。

5.  辅助功能与提示
    ◦   登录页提示：在登录页面，需有文字提示：“请提前下载《诚信承诺书》用于后续提交，《诚信承诺书》需要学生和指导教师签字”。

    ◦   附件下载：需提供《诚信承诺书》空白模板的下载链接。

    ◦   草稿保存：提交页面有“保存”按钮，暗示系统需支持保存草稿功能，允许用户分多次完成材料上传，最后再统一提交。

二、 非功能性需求与隐含规则

1.  单向流程：从“选择方向”开始，路径不可逆（确认后无法更改类型）。
2.  状态管理：用户登录后，系统需记住其选择的比赛方向，并始终保持一致。例如，选择了“创新设计类”的用户，再次进入时应直接进入作品提交页面，而非重新选择。
3.  文件管理：需实现前端文件格式(.pdf, .mp4)和大小(30M, 100M)的即时校验，并给予用户清晰的上传反馈（成功、失败、替换）。
4.  数据关联：所有上传的文件需与学生的账号（报名号）及所选赛道强关联。
